ROUTINE – turning this into an Android app (no coding needed)

Option A – Install as an app straight from Chrome (5 minutes)
1. Create a free GitHub account, make a new PUBLIC repository named "routine".
2. Upload all files in this folder (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png).
3. Repository > Settings > Pages > Source: "Deploy from a branch", branch "main", folder "/ (root)". Save.
4. After a minute, open https://<your-username>.github.io/routine/ in Chrome on your phone.
5. Chrome menu (⋮) > "Add to Home screen" / "Install app". It gets its own icon, opens full-screen, and works offline.

Option B – Get a real .apk file
1. Do steps 1–4 above.
2. On a computer, open https://www.pwabuilder.com and paste your github.io URL.
3. Click "Package for stores" > Android > "Generate". Download the zip; it contains a signed .apk.
4. Copy the .apk to your phone and open it (allow "Install unknown apps" for your file manager when asked).

Your data stays on the phone. Use More > Export backup regularly, e.g. monthly.
Note: data in this app version is separate from the claude.ai link version; move it across with Export / Restore.
